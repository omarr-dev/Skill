# Exam Sprint: a Claude skill

Turns any course's slides, past exams, and classmates' notes into a fun, mobile-first study app built to get full marks in the least time.

## Install
Copy the `exam-sprint` folder into `~/.claude/skills/` (Claude Code), or upload it as a skill in claude.ai.

## Use
Send Claude your slides, the exam announcement, and any past exams or notes, then say: "use exam-sprint".
